# CrossWatch for Home Assistant

CrossWatch packaged as a Home Assistant App.

## Configuration

CrossWatch stores its persistent data in the Home Assistant App configuration
directory, mounted inside the container as `/config`.

## Web interface

After starting the App, open:

http://HOME_ASSISTANT_IP:8787

## Architecture

This App is configured for `aarch64`.
